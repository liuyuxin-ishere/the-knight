# The Knight

基于 Unity 的第三人称点击移动 RPG。玩家在导航网格上点地行走，点击敌人进入战斗，击败怪物获得经验并升级，也可以在场景之间传送并保存进度。

当前编辑器版本：**Unity 6000.3.22f1**。渲染使用 Universal Render Pipeline，镜头使用 Cinemachine FreeLook。

## 已实现功能

- **主菜单**：新游戏、继续游戏、退出。新游戏会清空本地存档并进入第一关；继续游戏会回到上次保存的场景。
- **点击移动**：左键点击地面，角色沿 NavMesh 走向落点。鼠标悬停在地面、敌人、可攻击物和传送点上时，光标会切换。
- **战斗**：左键点击敌人后走近并攻击，伤害在最小伤害和最大伤害之间随机，并计算暴击。攻击有冷却。防御会抵消部分伤害。
- **角色成长**：生命、防御、攻击范围、冷却、暴击率和暴击倍率由 ScriptableObject 配置。击杀获得经验，升级后提高生命上限并回满生命。界面显示等级、生命和经验。
- **敌人 AI**：守卫、巡逻、追击、死亡。守卫会回到原位，巡逻会在范围内找点并张望，发现玩家后追击，死亡后碰撞关闭并在短时间后消失。玩家死亡时，在场敌人会收到通知并停止行动。
- **敌人技能**：Grunt 近战击退并让玩家进入眩晕。Golem 可以踢击，也会投掷石块；玩家打中飞行中的石块后，石块会反向飞向投掷者。
- **场景切换**：走到传送点按 `E`。同一场景内会直接传送，跨场景会先保存数据、异步加载，再在目标点生成玩家并读档。
- **存档**：角色数据序列化为 JSON，写入 PlayerPrefs，同时记录当前场景名。游戏中按 `S` 保存，按 `L` 读取。

主流程场景是 `Assets/Scenes/HomeScene.unity`（主菜单）和 `Assets/Scenes/SampleScene.unity`（第一关）。打包发布和 Timeline 过场还没有做。

## 操作

| 输入 | 作用 |
| --- | --- |
| 鼠标左键点击地面 | 移动到该位置 |
| 鼠标左键点击敌人 | 靠近并攻击 |
| 鼠标左键点击石块 | 把石块打回去 |
| `E` | 站在传送点内时切换场景或传送 |
| `S` | 保存玩家数据和当前场景 |
| `L` | 读取玩家数据 |

自由镜头跟随玩家。主菜单里选「新游戏」或「继续游戏」开始。

## 下载与运行

1. 安装 [Unity Hub](https://unity.com/download)，并安装与项目一致的编辑器 **6000.3.22f1**。
2. 克隆仓库：

```bash
git clone https://github.com/liuyuxin-ishere/the-knight.git
```

3. 在 Unity Hub 中选择 **Add project from disk**，选中克隆下来的项目根目录（包含 `Assets`、`Packages`、`ProjectSettings` 的那一层）。
4. 第一次打开会重新导入资源和 Package。`Library`、`Temp`、`Logs` 不在仓库里，这一步需要等待完成。
5. 打开 `Assets/Scenes/HomeScene.unity`，点击 Play。

从主菜单进入关卡。若要直接看关卡，也可以打开 `Assets/Scenes/SampleScene.unity` 再播放，但继续游戏和跨场景传送依赖主菜单流程里保存的场景名。
